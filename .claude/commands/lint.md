# /lint

Lance `python scripts/lint_wiki.py` (skill `lint-wiki`), puis corrige ce qui est sûr (liens, frontmatter, index) et liste le reste avec une proposition. Format de fin : TL;DR / AUTO / TOI / ALERTE.
