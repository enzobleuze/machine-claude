# /fin : le wiki s'améliore à chaque session

1. **Enrichir** : ce qui a été appris ou décidé va dans le wiki (nouveau principe dans `wiki/principes/`, client dans `wiki/clients/`, contenu publié dans `wiki/contenu/`, décision dans `wiki/strategie/`).
2. **Relier** : chaque nouvelle page a au moins 3 [[liens]] vers des pages existantes, et les pages liées pointent en retour.
3. **Index et log** : nouvelles pages dans `index.md`, une entrée datée dans `log.md` (ce qui a été fait, ce qui reste).
4. **Mémoire** : chaque correction ou préférence donnée aujourd'hui devient un fichier mémoire (Pourquoi + Comment l'appliquer), une ligne dans `MEMORY.md`.
5. **Tâches et parcours** : états des tâches touchées à jour, `wiki/maps/parcours.md` coché si une étape a passé son test.
6. **Trous** : nomme en une ligne les pages qui manquent.
7. **Commit** : `git add -A` puis un commit qui résume la session.

Réponds au format TL;DR / AUTO / TOI / ALERTE.
